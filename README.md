# ScamLens

**Pause before you click.** ScamLens is a small, bilingual browser tool that checks suspicious text messages and emails for common warning signs. It runs locally in your browser, with no account, server, AI service, or API key.

- [Open the Dutch checker](index.html) · [Try the Dutch five-minute lesson](learn.html)
- [Open the English checker](en/index.html) · [Try the English five-minute lesson](en/learn.html)

## Run it

Open `index.html` in a modern browser, or open `en/index.html` for English. No build step or dependencies are needed.

## What it checks

The checker looks for urgency, requests for payment or credentials, links, familiar organisation names, and unexpected prizes. The optional five-minute lesson presents three fictional scenarios and explains safer next steps.

## Privacy and limitations

Message text is processed only in the browser and is not sent or stored. Remove personal details before pasting. ScamLens uses simple text rules, not AI or a reputation database. It can miss new or differently worded scams, and legitimate messages can trigger signals. Results are not proof of fraud or safety. Verify important requests through an official channel you find yourself.

## Technology

Vanilla HTML, CSS, and JavaScript. No external dependencies.
